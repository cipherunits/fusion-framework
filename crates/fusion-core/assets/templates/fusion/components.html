Toast

Hot notifications with six positions (top/bottom × left/center/right), inspired by react-hot-toast. Mount the toaster once, then fire from JS or a Fusion button.

Usage

{{<fusion.toast position="top-center" />}}

{{<fusion.button
  label="Save"
  variant="primary"
/>}}
<!-- add data-fusion-toast on the rendered button, or call: -->
<script>
  FusionToast.success("Saved!", { position: "top-right" });
  FusionToast.error("Failed", { position: "bottom-center" });
</script>

<link rel="stylesheet" href="components/toast/toast.css" />
<script src="components/toast/toast.js"></script>

Positions

<button
  type="button"
  class="fusion-btn fusion-btn--primary"
  data-fusion-toast="Saved!"
  data-toast-variant="success"
  data-toast-position="top-right"
>Save</button>

Variants

FusionToast.success("Successfully toasted!", { position: "top-center" });
FusionToast.error("Something went wrong");
FusionToast.warning("Check your settings");
FusionToast.info("New update available");

Modal

Centered dialog. Variants success, warning, error — or omit for a fully custom panel. Size and animation are tunable per open.

Usage

{{<fusion.modal
  variant="warning"
  title="Delete item?"
  message="This cannot be undone."
  size="md"
  animation="scale"
  duration={220}
/>}}

FusionModal.open({
  variant: "success",
  title: "Saved",
  body: "Your changes are live.",
  size: "lg",           // sm | md | lg | xl | "480px"
  animation: "slide",   // scale | fade | slide | none
  duration: 280
});

<button
  type="button"
  class="fusion-btn fusion-btn--primary"
  data-fusion-modal-open
  data-modal-variant="error"
  data-modal-title="Upload failed"
  data-modal-body="Please try again."
  data-modal-size="sm"
  data-modal-animation="fade"
>Show error</button>

<link rel="stylesheet" href="components/modal/modal.css" />
<script src="components/modal/modal.js"></script>

Variants

FusionModal.success({ title: "Payment successful", body: "…" });
FusionModal.warning({ title: "Delete workspace?", body: "…" });
FusionModal.error({ title: "Sync failed", body: "…" });
FusionModal.open({ title: "Custom modal", body: "…" }); // no variant

Size & animation

FusionModal.open({
  title: "Tuned",
  body: "Custom size + motion",
  size: "480px",
  animation: "slide",
  duration: 320,
  easing: "cubic-bezier(0.22, 1, 0.36, 1)"
});
